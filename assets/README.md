# assets/

Real screenshots and a demo GIF for the README go here. The README's
`<img src="assets/preview.png">` points at this folder.

## What to add before publishing v1.0

|---|---|---|
| `preview.png` | 1200×630 | Hero shot — landing page with the Fisna logo + tagline + first suggestion cards visible |
| `landing.png` | 1440×900 | Full landing page in dark mode |

## Tools

- **ScreenToGif** (Windows, free) for the demo GIF
- **ShareX** for full-page screenshots
- **Chrome DevTools → Device Toolbar** for responsive (1440, 1280, 768, 390)
- **Figma / Photopea** to add a subtle gradient overlay and the wordmark in the corner

## Naming

Use kebab-case (`chat-dark.png`, not `Chat Dark.PNG`). Lowercase + dashes = URL-friendly.
